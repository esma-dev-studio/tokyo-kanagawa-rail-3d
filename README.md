# Tokyo Kanagawa Rail 3D

東京・神奈川エリアの鉄道・地下鉄 全48路線(約800駅)を、暗い3D空間に発光ラインで俯瞰表示するWebアプリ。
路線形状・駅位置は国土数値情報 鉄道データ(N02)由来の実データ。

## 起動方法

```bash
npm install
npm run dev
```

表示されたURL(既定: http://localhost:5183)をブラウザで開く。

本番ビルド: `npm run build` → `dist/` に出力(確認は `npm run preview`)。
※ ビルドが exit code 9 で無言失敗する場合は `dist/` フォルダが他プロセスにロックされているので、`dist/` を削除してから再実行する。

## 収録路線(48路線)

- **地下鉄(15)**: 東京メトロ9路線 / 都営4路線 / 横浜市営ブルーライン・グリーンライン
- **JR(8)**: 山手線 / 京浜東北・根岸線 / 中央線 / 総武線 / 東海道線 / 横須賀線 / 南武線 / 横浜線
- **私鉄(25)**: みなとみらい線 / 東急6路線 / 京急5路線 / 小田急3路線 / 京王3路線 / 相鉄3路線 / 西武2路線 / 東武2路線

補足:
- 湘南新宿ライン・上野東京ラインは運転系統(専用線路を持たない)のため対象外
- 京浜東北線は線路データ上「東北線(東京以北)+根岸線(横浜以南)」で構成。東京〜横浜間は東海道線の線路上を走るため、東海道線のラインが対応する
- 山手線・横須賀線などは線路の正式区間で収録(例: 山手線=品川〜新宿〜田端。東側は東海道線・東北線側に含まれる)

## データについて

- 出典: 以下の国土数値情報(国土交通省)を加工して作成
  - 鉄道データ(N02-24): https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2024.html
  - 行政区域データ(N03-2025・県境/海岸線の抽出元): https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2025.html
- **深度・高度は元データに存在しないため、視認性優先の概算値**(路線ごとの基準高さ+駅/区間単位の調整)を付与している

### データの再生成・路線の追加

1. 上記ページから `N02-XX_GML.zip` をダウンロードして展開(UTF-8フォルダにGeoJSONが入っている)
2. 路線の追加・高さ調整は [scripts/n02.config.mjs](scripts/n02.config.mjs) を編集
   (N02の事業者名・路線名は `N02_004` / `N02_003` の値をそのまま指定する)
3. 変換を実行:

```bash
node scripts/convert-n02.mjs <展開したUTF-8フォルダのパス>
```

→ `src/data/generated/n02Lines.json` が更新される。

手書きデータで路線を足したい場合は `src/data/buildLine.ts` で `RailLine` を構築し、
`src/data/railData.ts` の配列に加えればよい。

### 県境・海岸線の再生成

1. 行政区域データ(N03)のページから対象都県(既定: 埼玉11・千葉12・東京13・神奈川14・山梨19・静岡22)の
   `N03-XXXXXXXX_YY_GML.zip` をダウンロードして展開(GeoJSON同梱)
2. 変換を実行(フォルダ以下の *.geojson を再帰的に読む):

```bash
node scripts/convert-n03.mjs <展開したフォルダの親フォルダ>
```

→ `src/data/generated/boundaries.json` が更新される。
市区町村ポリゴンの共有辺を集計し、都道府県が異なる辺=県境、共有されない辺=海岸線(湖岸含む)として抽出している。
対象エリアに接する都県をすべて入力しないと、県境が海岸線として誤分類されるので注意。

## ディレクトリ構成

```
scripts/         N02/N03 → アプリ用データの変換スクリプト + 路線設定
src/
├─ components/   UI(操作パネル・ポップアップ・スケール・ステータスバー・コンパス)
├─ data/         路線データ(generated/ = N02由来の生成物)
├─ hooks/        React と Three.js の接続
├─ scenes/       Three.js(シーン統括・環境・路線描画・駅描画)
├─ types/        型定義(RailLine / Station / Operator など)
└─ utils/        座標変換・高さロジック・ラベル表示制御
```

## 技術スタック

Vite / React 18 / TypeScript / Three.js(OrbitControls, Line2, InstancedMesh, CSS2DRenderer, UnrealBloom)

## 実装メモ

- 駅マーカーは路線ごとに InstancedMesh 化(約1000駅でもドローコールを抑制)
- 駅名ラベルはDOM(CSS2D)描画。スクリーン空間の衝突判定で重なりを間引き、
  表示距離はズームに連動
- 地下鉄はGL±0の半透明地表面の下に描画され、透かして見える
- 路線同士の交差が読めるよう、地下鉄は路線ごとに基準深度を数mずつずらしている
- 地表面には海岸線(青系)と県境(紫系)をうっすら描画。「地図の濃さ」スライダーに連動する
